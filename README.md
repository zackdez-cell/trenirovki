# Тренировки — план на неделю для Android

Приложение показывает план тренировок на неделю, позволяет ставить галочки и присылает уведомление в назначенное время.

## Формат плана

```
Понедельник
10:00 10 отжиманий
10:30 30 пресс

Вторник
9:00 Бег 3 км

Каждый день
22:00 Растяжка
```

- День недели пишется на отдельной строке, полностью или коротко: Пн, Вт, Ср…
- Под днём идут строки «ЧЧ:ММ упражнение». Время можно писать и через точку: 9.30.
- «Каждый день» или «Ежедневно» добавляет упражнения во все семь дней.
- Лишние символы из чата (жирный шрифт, решётки, маркеры списков) не мешают.

Новый план заменяет старый. Галочки сами обнуляются в начале каждой недели.

## Сборка

Каждый push в ветку `main` запускает GitHub Actions. Он собирает `Trenirovki.apk` и выкладывает его в раздел Releases.
Последняя версия всегда лежит по ссылке `https://github.com/<владелец>/<репозиторий>/releases/latest/download/Trenirovki.apk`.

APK подписан постоянным ключом `app/weekplan.keystore`, поэтому новые версии ставятся поверх старых, и план не теряется.
